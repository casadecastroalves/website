Painel de conteúdo do site

O cliente edita textos aqui. Ao publicar, o GitHub actualiza o site automaticamente (Cloudflare) em 1–3 minutos.

Entrar: casadecastroalves.com.br/admin/

Primeiro acesso: é preciso configurar login GitHub (uma vez). Peça ao técnico para activar o OAuth — instruções abaixo.

Quem pode editar

O painel usa login GitHub (não é e-mail/senha do site). Só contas convidadas no repositório do site podem publicar:

  • casadecastroalves@gmail.com — conta GitHub casadecastroalves (proprietário)
  • grimaux@gmail.com — conta GitHub Grimaux (colaborador)

Se o login falhar, confirme que entrou com a conta GitHub correcta (não outra conta pessoal).

Fluxo de trabalho

  1. Entrar em /admin/ com conta GitHub autorizada
  2. Editar o conteúdo desejado
  3. Clicar em Publicar (grava no GitHub)
  4. Aguardar 1–3 min — o site online actualiza sozinho

Configuração técnica (OAuth GitHub — uma vez)

Se ao clicar Entrar com o GitHub aparecer erro de GITHUB_CLIENT_ID, falta este passo:

  1. Entrar no GitHub como casadecastroalves
  2. Criar OAuth App:
    • Nome: Decap CMS Casa Castro Alves
    • Homepage: https://casadecastroalves.com.br
    • Callback: https://casadecastroalves.com.br/api/callback
  3. Copiar Client ID e gerar Client Secret
  4. Cloudflare → Workers & Pages → projecto do site → Settings → Environment variables:
    • GITHUB_CLIENT_ID = Client ID
    • GITHUB_CLIENT_SECRET = Client Secret (marcar como Encrypt)
    • Activar em Production e Preview
  5. Deployments → Retry deployment (obrigatório para activar as variáveis)
  6. Testar de novo em /admin/ com conta GitHub autorizada
