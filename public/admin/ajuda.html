Painel de conteúdo do site

O cliente edita textos aqui. Ao publicar, o GitHub actualiza o site automaticamente (Cloudflare) em 1–3 minutos.

Entrar: casadecastroalves.com.br/admin/

Primeiro acesso: é preciso configurar login GitHub (uma vez). Peça ao técnico para activar o OAuth — instruções abaixo.

O que pode editar

  • Contato — telefone, WhatsApp, e-mail, endereço
  • Edições — programação, artistas, textos, links YouTube
  • Linha do tempo — cards em Shows e Edições
  • Design Caboclo — designers e textos do showroom
  • Textos longos das edições — descrições e programação detalhada

Fluxo de trabalho

  1. Entrar em /admin/ com conta GitHub autorizada
  2. Editar o conteúdo desejado
  3. Clicar em Publicar (grava no GitHub)
  4. Aguardar 1–3 min — o site online actualiza sozinho

Configuração técnica (OAuth GitHub — uma vez)

  1. GitHub → Settings → Developer settings → OAuth Apps → New OAuth App
  2. Homepage URL: https://casadecastroalves.com.br
  3. Authorization callback URL: https://casadecastroalves.com.br/api/callback
  4. Cloudflare Pages → Settings → Environment variables: GITHUB_CLIENT_ID e GITHUB_CLIENT_SECRET (valores da OAuth App)
  5. Convidar o cliente como colaborador do repositório casadecastroalves/website no GitHub
  6. Após o próximo deploy, entrar em /admin/ e fazer login com GitHub
